# Quiet.md 1.0.1

## 中文

- DocxXML 笔记可插入并编辑原生画板。画板使用 gpui-excalidraw 的画布、工具栏和属性面板，保存后在正文显示可再次编辑的预览。
- 支持导入和导出 `.excalidraw`，也支持带可编辑图源的 PNG 和 SVG。导出带图片的 Markdown 时，会一并写出画板预览和可编辑图源。
- 画板素材面板仅在当前会话有效。
- DocxXML 文档库把图片、附件和画板图源分别保存在 `Image/`、`Files/` 和 `Drawing/`。
- 更新开始指南和应用界面，示例库可从仓库单独取得。

## English

- Insert and edit native drawings in DocxXML notes. The editor uses the gpui-excalidraw canvas, toolbar, and properties panel. Saved drawings appear as previews you can reopen and edit.
- Import and export `.excalidraw` files, PNGs, and SVGs with embedded drawing data. Markdown export with images includes both the drawing preview and its editable source.
- The drawing library panel is scoped to the current editor session.
- DocxXML libraries store images, attachments, and drawing sources in `Image/`, `Files/`, and `Drawing/`.
- Refresh the getting-started guide and app interface. The sample library is available separately in the repository.
