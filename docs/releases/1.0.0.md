# Quiet.md 1.0.0

## 中文

- 发布为正式 Release，标记为 Latest，不再作为 Pre-release。
- 优化长代码和大表格的布局、绘制与滚动，减少光标闪烁带来的 CPU 开销。
- 搜索结果使用虚拟列表，降低万篇文档库的查询停顿和内存峰值，保持结果排序与键盘操作。
- 修复窗口关闭后文档库轮询任务仍运行的问题。
- 跳过内容没有变化的保存；解析缓存按文档增量写入，减少全库缓存和备份的磁盘写入。
- 优化长文档普通输入与退格的渲染缓存。
- Git 历史支持带格式的 XML 正文对比。
- 增加资源压测及界面回归工具。测量结果与现有限制见[性能修复报告](https://github.com/iuxt/quiet-md/blob/v1.0.0/docs/PERFORMANCE-FIXES-2026-11-18.md)。

## English

- Publish as a stable release, marked Latest rather than Pre-release.
- Improve layout, painting and scrolling for long code blocks and large tables, reducing CPU use during caret blinking.
- Virtualize search results to reduce pauses and memory peaks in large libraries while preserving ranking and keyboard navigation.
- Stop library polling tasks after their windows close.
- Skip unchanged saves and persist parsed documents incrementally to reduce disk writes.
- Reuse rendering indexes during ordinary typing and backspacing in long documents.
- Show formatted XML document diffs in Git history.
- Add resource stress tests and UI regression coverage. See the [performance report](https://github.com/iuxt/quiet-md/blob/v1.0.0/docs/PERFORMANCE-FIXES-2026-11-18.md) for measurements and remaining limits.
