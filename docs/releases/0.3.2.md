# Quiet.md 0.3.2

## 中文

- Git 变更面板新增全部暂存、全部取消暂存和工具栏提交按钮。
- 提交说明默认填写当天日期，文件对比改用单列行号，调整推送和拉取图标。
- 发布工具新增 `python3 scripts/version.py release`，校验版本与发布提交后自动创建并推送版本 tag；支持失败重试，拒绝覆盖冲突 tag。

## English

- Stage or unstage all changes and commit directly from the Git panel toolbar.
- Commit messages default to today's date. File diffs use one line-number column, with updated push and pull icons.
- Run `python3 scripts/version.py release` to validate the version and release commit, then create and push the matching Git tag. Failed pushes can be retried; conflicting tags are never overwritten.
