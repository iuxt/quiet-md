# Quiet.md 0.2.0

## 中文

这个版本汇总了分叉仓库中文档管理、备份和更新的改进。

- **Git 备份**：可选的内置 Git 备份，支持本地提交、历史浏览、HTTPS / SSH 推送、克隆和快进拉取。图片和附件使用 Git LFS，无需安装 Git 或 Git LFS。
- **版本历史**：自动保留文档快照，可以预览历史正文、对比改动、命名重要版本并恢复。
- **文档库存储**：JSON 管理虚拟文件夹、标题和排序，正文保存在固定的 UUID 文件名下。移动和重命名只更新元数据；旧文档库升级时保留备份。
- **图片布局**：把图片拖到另一张图片旁边可组合为分栏，也支持分栏内的图片排序。
- **回收站**：删除的文档一直保留到手动恢复，回收站也纳入 Git 备份。
- **更新**：下载和更新源统一为 `iuxt/quiet-md` 的 GitHub Releases；更新包通过签名验证后，保存打开的文档并重启安装。正式发布流程支持多平台签名、验签和 Release 草稿。
- **修复**：恢复带 Windows 路径的图片，并修复 Windows 上的 HTTP 测试兼容性。

## English

This release brings together document management, backup, and update improvements in this fork.

- **Git backup**: optional built-in local commits, history browsing, HTTPS / SSH push, clone, and fast-forward pull. Images and attachments use Git LFS; no Git or Git LFS installation is required.
- **Version history**: automatic document snapshots with previews, change comparisons, named versions, and restore.
- **Library storage**: JSON manages virtual folders, titles, and ordering. Document bodies use fixed UUID filenames, so moving or renaming only changes metadata. Upgrades from older libraries preserve a backup.
- **Image layout**: drag an image beside another to arrange them in columns, and reorder images within columns.
- **Trash**: deleted documents remain until restored. Trash is also included in Git backup.
- **Updates**: downloads and updates use `iuxt/quiet-md` GitHub Releases. Update packages are signature-verified before saving open documents and restarting to install. The release workflow supports platform signing, verification, and Release drafts.
- **Fixes**: restore images with Windows paths and improve HTTP test compatibility on Windows.

## 更新说明 / Update notes

首次使用此分叉时，请手动安装正式签名版本。后续应用内更新需要发布为 Latest 的正式 Release；普通 CI 产物和 Release 草稿不会进入更新通道。

Install a signed release manually when switching to this fork. Subsequent in-app updates require a published Latest release; ordinary CI artifacts and Release drafts are outside the update channel.
