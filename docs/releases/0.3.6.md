# Quiet.md 0.3.6

## 中文

- 修复 Windows 发布检查中的换行、中文输出和路径分隔符兼容问题，以及 macOS 临时 keychain 的签名查找。

- 发布流程改用免费测试包，无需 Apple 开发者会员、Windows 代码签名证书或 Minisign 发布密钥。
- 提供 macOS Apple Silicon / Intel ZIP、Windows x64 安装包和 Linux x86_64 AppImage，每个包附 SHA-256 校验文件。
- macOS 采用 ad-hoc 签名、未经 Apple 公证；Windows 安装包未签名，系统可能显示安全提示。
- 此版本标记为 Pre-release，需要手动下载安装，不进入应用内自动更新通道。
- 包含 0.3.2 的 Git 工具栏改进：全部暂存、全部取消暂存、工具栏提交、默认日期说明和单列行号对比。

## English

- Fix line endings, Unicode output and path separators in Windows release checks, plus signing identity lookup in temporary macOS keychains.

- Publish free test builds without Apple Developer membership, a Windows code-signing certificate, or a Minisign release key.
- Download macOS Apple Silicon / Intel ZIPs, a Windows x64 installer, or a Linux x86_64 AppImage, each with a SHA-256 checksum.
- macOS apps are ad-hoc signed and not notarized. The Windows installer is unsigned; the operating system may show security warnings.
- This prerelease requires manual download and installation and is outside the in-app update channel.
- Includes the 0.3.2 Git toolbar improvements: stage all, unstage all, commit, date-based default messages, and single-column diff line numbers.
