# 画板本地编辑

对照 [Excalidraw](https://github.com/excalidraw/excalidraw/tree/091bc0e9d86fef5727c3f4d148a73e441b064ed1) 的画布操作、快捷键和文件编码，补充 Quiet.md 内嵌画板的本地编辑能力。对照入口是上游的 `HelpDialog.tsx`、`actions`、`element/src/flowchart.ts` 和 `data`。这里记录行为和验证方式，界面以 Theme token 和代码为准。

## 操作

| 能力 | 入口与行为 |
|---|---|
| 多选 | Shift 点击、拖框、⌘A；⌘点击或⌘拖框直接选择编组内的元素 |
| 编组 | ⌘G / ⌘⇧G；双击进入编组，Esc 退出；复制时重新生成组和元素 ID |
| 变换 | 拖动、方向键微移、Shift 加速、Alt 拖动副本；四角缩放、旋转；Shift 约束比例或 45°，Alt 从中心绘制/缩放 |
| 精确输入 | 属性面板的位置、尺寸和角度；描边宽度、字号、自定义十六进制颜色 |
| 对齐与分布 | 属性面板和右键菜单；⌘⇧方向键对齐四边；按编组整体计算位置 |
| 图层、锁定与翻转 | 属性面板、右键菜单；⌘[ / ⌘] 调整层级，⌘⇧L 锁定，菜单解锁全部；⇧H / ⇧V 翻转 |
| 线条与箭头 | 选中后直接拖头尾；⌘Enter 编辑节点；拖中点插入节点，Shift 多选节点、方向键移动、Delete 删除；多次点击绘制多段线，Enter 完成 |
| 箭头样式 | 起点/终点均可设箭头、圆、菱形、基数等端点；支持直线、曲线和折线，折线中段可拖动 |
| 连接 | 箭头端点吸附到形状，移动形状后跟随；拖动时按住⌘停用绑定与网格吸附 |
| 流程图 | 选中形状后⌘方向键创建相邻形状及连接箭头，Alt 方向键沿已有连接切换 |
| 文字 | 双击或 Enter 编辑；支持多行，⌘Enter / Esc 完成；空内容删除原文字；W 绑定/解绑形状文字，Alt W 切换自动宽度 |
| 文字样式 | 颜色、内置字体、字号、水平和垂直对齐；⌘⇧< / ⌘⇧> 改字号；绑定文字随形状旋转和折行 |
| 图片 | 文件选择或剪贴板插入；旋转、翻转；Enter / 双击进入裁剪，拖角裁剪，属性面板还原裁剪 |
| 画框 | F 绘制；内容加入画框，移动画框携带内容；调整画框边界保留内容尺寸；画布与导出均裁切越界内容，Enter 编辑名称 |
| 剪贴板 | ⌘C / X / V；原版 Excalidraw 剪贴板、图片、纯文字；⌘⇧V 按文字粘贴；Alt⇧C 复制 PNG；⌘Alt C / V 复制和粘贴样式 |
| 素材库 | ⇧L 打开；添加选区、插入、移除、导入/导出 `.excalidrawlib`；保存在文档库 `.quiet/drawing-library.excalidrawlib` |
| 辅助工具 | 橡皮擦连续擦除、Alt 恢复本次待擦元素；B 填色、I 取色、K 临时激光笔；激光轨迹不写入图源 |
| 视图 | 空格/中键/H 拖动平移、滚轮；⌘±、⌘0、⇧1 全部、⇧2 选区；网格、Alt S 对象边缘/中心吸附与参考线、Alt Z 专注、Alt R 浏览模式、深色画布 |
| 查找与帮助 | ⌘F 查找文字，Enter / Shift Enter 切换；? 查看快捷键；右键操作菜单 |
| 文件与导出 | `.excalidraw`，含可编辑图源的 PNG/SVG；选区导出、透明背景、深色导出、PNG 1×/2×/3×倍率、可选嵌入图源；SVG 内嵌所用字体 |
| 撤销与保存 | 每次完整手势一个撤销步骤；⌘Z / ⌘⇧Z / ⌘Y；⌘S 保存草稿到笔记，未保存离开时确认 |

macOS 用 ⌘，其他平台用 Ctrl。原有入口和工具顺序保留，新增辅助工具在“更多工具”里。

## 边界

这是原生 GPUI 画板，不嵌入浏览器版 Excalidraw。形状、手绘和文件模型复用 vendored Rust 实现；折线自动布线、字体测量、吸附和取色使用本地几何实现，复杂场景的结果可能与上游不同。取色读取画板元素的颜色，不读取其他应用或整块屏幕；填色作用于已有图形/线条区域。

在线协作、服务端分享、网页嵌入、AI 和 Mermaid 转换不属于这次本地元素编辑范围。素材库只在本机读写，不访问在线素材站。

继续保留资源边界：图源 8 MiB、600 元素、单线 3000 点/场景 30000 点、32 张图片/总计 1600 万像素、素材库 64 项、撤销 32 步。编辑预览最长边 2048 像素，PNG 文件导出最长边 4096 像素。选区剪贴板和导出只携带选中图片的数据，保留引用的文字、画框成员和已知绑定关系；未知图源字段在原元素编辑后继续保留。

## 验证

- `scripts/check.sh`：工作区测试、指南往返、标准和 devtools 构建的 clippy。
- `cargo test --release drawing`：坐标/绑定、旋转文字、编组引用、节点、折线中段、画框缩放、图片裁剪/翻转像素、选区资源、PNG/SVG 元数据、Unicode 和解压上限。
- `cargo build --release --features devtools` 后运行 `python3 tools/harness/drawing.py`：在临时文档库里操作实际界面，保存后检查图源。剪贴板使用模拟内容。
