# 画板本地编辑

对照 [Excalidraw](https://github.com/excalidraw/excalidraw/tree/2c3dcc06ec807e81ab9437eceb1a8f7a3c590743) 的画布操作、快捷键和文件编码，补充 Quiet.md 内嵌画板的本地编辑能力。对照入口是上游的 `HelpDialog.tsx`、`actions`、`element/src/flowchart.ts` 和 `data`。这里记录行为和验证方式，界面以 Theme token 和代码为准。

## 操作

| 能力 | 入口与行为 |
|---|---|
| 正文中的画板 | 单击预览选中画板块，双击预览进入编辑 |
| 多选 | Shift 点击、拖框、套索、⌘A；⌘点击或⌘拖框直接选择编组内的元素 |
| 编组 | ⌘G / ⌘⇧G；双击进入编组，Esc 退出；复制时重新生成组和元素 ID |
| 变换 | 拖动、方向键微移、Shift 每次移动 5 个单位，启用网格后 Shift 用于单单位微移、Alt 拖动副本；四角缩放、旋转，单个常用形状足够大时可拖边中点单独调整宽高；Shift 约束比例或限制线段方向为 15° 的倍数，Alt 从中心绘制/缩放 |
| 精确输入 | 属性面板的位置、尺寸和角度；描边宽度、字号、自定义十六进制颜色 |
| 对齐与分布 | 属性面板和右键菜单；⌘⇧方向键对齐四边；按编组整体计算位置 |
| 切换形状 | Tab / Shift+Tab 轮换，右键或命令面板打开形状列表，直接选择目标形状 |
| 图层、锁定与翻转 | 属性面板、右键菜单；⌘[ / ⌘] 调整层级，⌘⇧L 锁定，菜单解锁全部；⇧H / ⇧V 翻转 |
| 线条与箭头 | 选中后直接拖头尾；中间点可直接拖出曲线；矩形选框的四角缩放整条线，上方圆点旋转，选框随线旋转；⌘Enter 编辑更多节点；拖中点插入节点，Shift 多选节点、方向键移动、Delete 删除，⌘D 复制直线或曲线上的选中节点；多次点击绘制多段线，Enter 完成 |
| 箭头样式 | 起点/终点均可设箭头、圆、菱形、基数等端点；支持直线、曲线和折线，折线中段可拖动，文字标签可沿连线拖动 |
| 连接 | 箭头按形状轮廓和距离吸附，不会绑定到菱形或椭圆外接矩形的空白角落。绑定后会随形状移动；拖动一端时另一端固定。默认吸附到形状边中点，可在画布菜单关闭；拖动时按住⌘停用绑定与网格吸附 |
| 流程图 | 选中形状后⌘方向键创建相邻形状及连接箭头，Alt 方向键沿已有连接切换 |
| 文字 | T 点图形中心可绑定标签，拖动可先确定文字宽度；双击或 Enter 编辑；便签落下后可直接输入；支持多行，⌘Enter / Esc 完成；空内容删除原文字；W 绑定/解绑形状文字、为文字加矩形或用画框包裹选区，Alt W 切换自动宽度 |
| 文字样式 | 颜色、内置字体、字号、水平和垂直对齐；⌘⇧< / ⌘⇧> 改字号；绑定文字随形状旋转和折行 |
| 图片 | 文件选择、拖放或剪贴板插入；支持 SVG、PNG、JPEG、GIF、WebP、BMP、ICO；旋转、翻转；Enter / 双击进入裁剪，拖八个控制点裁剪，Shift 保持比例，Alt 固定中心。裁剪后拖动内部可调整取景，属性面板还原裁剪 |
| 画框 | F 绘制；内容加入画框，右键选择或移出全部内容。移动画框携带内容；调整画框边界保留内容尺寸；画布可切换画框显示，Enter 编辑名称。单独导出画框按边界裁切 |
| 剪贴板 | ⌘C / X / V；原版 Excalidraw 剪贴板、图片、纯文字，粘贴数值表可选柱状图、折线图或雷达图，分类标签会旋转并按列宽折行，单序列雷达图会对跨度较大的数据使用对数比例。右键菜单支持复制 SVG、文字和元素链接。⌘⇧V 按文字粘贴；Alt⇧C 复制 PNG；⌘Alt C / V 复制和粘贴样式 |
| 手绘 | P 自由绘制，轻点画点，连续落笔，支持固定/可变线宽。macOS 数位笔输入会在图源中记录压力；X 手绘转形状可识别矩形、菱形、椭圆、直线和箭头 |
| Mermaid | 直接粘贴源码，或从主菜单和命令面板输入。流程图可作为元素编辑，时序图、类图、状态图等可作为内嵌 SVG 插入 |
| 素材库 | ⇧L 打开；添加选区、插入、移除、导入/导出 `.excalidrawlib`；保存在文档库 `.quiet/drawing-library.excalidrawlib` |
| 辅助工具 | 橡皮擦连续擦除、Alt 恢复本次待擦元素；B 为封闭区域建立填色多边形、I 从画板合成像素取色、K 临时激光笔；激光轨迹不写入图源 |
| 视图 | 空格/中键/H 拖动平移、滚轮、PgUp / PgDn（Shift 横向）；支持触控板捏合缩放（macOS、支持手势协议的 Wayland）；⌘±、⌘0、⇧1 全部、⇧2 在视口内显示选区、⇧3 让选区填满视口；网格、Alt S 对象边缘/中心吸附与参考线、Alt Z 专注、Alt R 浏览模式、深色画布、小地图（点击或拖动定位）、Alt / 画板统计。随图源保留网格开关、间距和主线间隔 |
| 查找与帮助 | ⌘F 查找文字，Enter / Shift Enter 切换；⌘⇧P 或 ⌘/ 搜索命令，? 查看快捷键；右键操作菜单 |
| 文件与导出 | `.excalidraw`，含可编辑图源的 PNG/SVG。按住 Shift 拖入图源可在落点插入元素。图片默认导出已有选区，未选中元素时导出整张图。图源文件保存整张画板。图片支持透明背景、深色导出、PNG 1×/2×/3×倍率、实时预览，可选嵌入图源（默认关闭）。SVG 内嵌所用字体 |
| 撤销与保存 | 每次完整手势一个撤销步骤；⌘Z / ⌘⇧Z / ⌘Y；⌘S 保存草稿到笔记，未保存离开时确认 |

macOS 用 ⌘，其他平台用 Ctrl。原有入口和工具顺序保留，新增辅助工具在“更多工具”里。

工具栏下方会根据当前工具、选区和手势显示提示，例如多段线绘制、节点编辑、文字输入和图片裁剪。提示场景参考上游的 [HintViewer](https://github.com/excalidraw/excalidraw/blob/2c3dcc06ec807e81ab9437eceb1a8f7a3c590743/packages/excalidraw/components/HintViewer.tsx)。

## 边界

画板及其交互使用原生 GPUI。形状、手绘和文件模型复用 vendored Rust 实现。内置字体按字形宽度折行，缺字回退和输入法排版由原生文本系统负责。取色使用画布合成结果。

本地对齐范围包括原生画板、文件、剪贴板和本机素材库。复杂折线路由、文字排版、图表布局和 Mermaid 图片均由 Rust 实现。Mermaid 的高级语法和图片版式可能与官方不同。Windows 和 Linux 的画笔使用模拟压力。

本机资源上限为图源 8 MiB、16384 个元素、单线 32768 点或场景合计 524288 点、32 张图片/总计 1600 万像素、素材库 64 项、撤销 32 步。跨度可放入画布的远坐标图源会整体平移后打开。导入超出资源限制时会显示具体原因。编辑预览最长边 2048 像素，PNG 文件导出最长边 4096 像素。选区剪贴板和导出只携带选中图片的数据，保留引用的文字、画框成员和已知绑定关系；已删除元素和无引用图片不会写入文件或可编辑图源，元素的扩展字段随复制和粘贴保留。

## 验证

- `scripts/check.sh`：工作区测试、指南往返、标准和 devtools 构建的 clippy。
- `cargo test --release drawing`：坐标/绑定、旋转文字、编组引用、节点、折线中段、画框缩放、图片裁剪/翻转像素、选区资源、官方 v1/v2 可编辑图片、v1 素材库、PNG 导出尺寸、长 Unicode 文字 和解压上限。
- `cargo build --release --features devtools` 后运行 `python3 tools/harness/drawing.py`：在临时文档库里操作实际界面，保存后检查图源。剪贴板使用模拟内容。
